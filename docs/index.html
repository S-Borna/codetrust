About CodeTrust

CodeTrust (codetrust.ai) is the AI governance enforcement platform that prevents unsafe, hallucinated, and destructive AI-generated code from reaching production. Built by Said Borna, CodeTrust enforces 280 security rules across 10 inspection layers in real time.

AI Governance Gateway

76 real-time interception rules block destructive AI agent actions before execution. Categories include: heredoc injection, rm -rf prevention, curl-pipe-sh blocking, force push prevention, chmod 777 blocking, Docker privilege escalation, Terraform destroy protection, kubectl delete protection, credential exposure prevention, and AI agent code quality enforcement. Works with Claude Code, Cursor, GitHub Copilot, Windsurf, and Cline.

Hallucination Detection

CodeTrust detects AI hallucinations through 12 static detection rules and live registry verification. Static rules catch fabricated imports (ai_utils, ml_helpers), misspelled packages (requets, sklear, tenserflow), invented API endpoints, placeholder URLs, fake API keys, phantom file references, and hallucinated CLI flags. Live verification checks every import against PyPI, npm, crates.io, Go proxy, Maven, NuGet, RubyGems, and Packagist — packages not found are blocked immediately.

Trust Score and Drift Tracking

Quantified code safety score from 0 to 100 with per-category breakdown: anti-hallucination, anti-assumption, root cause analysis, container hygiene, CI/CD safety, and DevOps best practices. Baseline comparison detects safety regression over time.

Enterprise Features

CVE and vulnerability scanning with CVSS scoring. License compliance verification against enterprise policies. Cross-file dependency and impact analysis. Automated auto-fix pull requests with deterministic code transforms. Team management with role-based access control (RBAC). Signature validation with curated function database (33 modules, 209 functions). GDPR Art. 15 & 17 compliance. Append-only audit logs. Webhook integration with Slack and Microsoft Teams.

Distribution

Available as: CLI (pip install codetrust), VS Code extension (marketplace.visualstudio.com), GitHub Action (github.com/marketplace/actions/codetrust-scan), and MCP server for Claude Code and Cursor integration. 46 REST API endpoints. 21 MCP tools. Supports Python, JavaScript, TypeScript, Go, Rust, Java, C#, C++, Shell/Bash, Terraform/HCL, HTML, SQL, and YAML.

How CodeTrust Differs From Other Tools

Unlike Snyk, SonarQube, FOSSA, ESLint, and Semgrep which operate post-commit on human-written code, CodeTrust operates at the moment of AI code generation. It is the only platform that blocks AI agent commands before execution, detects hallucinated packages via live registry verification, and tracks code safety drift with quantified trust scores.
